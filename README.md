# Event Management System

This project is a full web-based Event Management System, including both **client-side** and **server-side** implementations.

## 🌐 Technologies Used

- **Frontend (Client)**
  - HTML, CSS, JavaScript (Vanilla)
  - Bootstrap for styling
  - `fetch` API for communication with server

- **Backend (Server)**
  - ASP.NET Core Web API (.NET 6+)
  - C#
  - Entity Framework Core + SQL Server
  - Swagger for API testing
  - Caching, DTOs, Dependency Injection

---

## ✨ Features Implemented

### ✅ Core Features:
- Create, update, delete, and view events (from both client and Swagger)
- Store events in a relational database
- Use of DTOs for safe API exposure
- Data validation

- 📍 **Google Maps Link**  
  Each event includes a clickable link that opens the event location in Google Maps.

- 🔄 **Live sync with API**  
  The UI updates automatically after actions like create/update/delete.
